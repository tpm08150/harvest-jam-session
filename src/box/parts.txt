# The groovebox: the studio for a Raspberry Pi with no screen (2026-09-20).
#
# The studio's manifest with the tape, the library, the jam, talkback, cloud sync and the sign-in
# gate left out — never parsed, never in memory — and shell/song.js, which is sequence numbers for
# the whole rack and a chain of them, in the launcher's place on the controller. The launcher's own
# code stays: it is the seam every change lands on, and the tempo head and the Settings tab are in
# it. Every other fragment is the studio's own file, so the two cannot drift.
